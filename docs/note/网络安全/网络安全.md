## 基础知识
### TCP/IP 协议
1. 层：
    - 层 2：数据链路层（以太网和ARP）
    - 层 3：网络层（IP，ICMP）
    - 层 4：传输层（TCP，UDP）
2. IP 地址：
    - A 类：0.0.0.0 - 127.255.255.255 后 24 位为主机 ID
    - B 类：128.0.0.0 - 191.255.255.255 后 16 位为主机 ID
    - C 类：192.0.0.0 - 223.255.255.255 后 8 位为主机 ID
    - D 类：224.0.0.0 - 239.255.255.255 后 28 位为地址范围
    - E 类：240.0.0.0 - 255.255.255.255 后 28 位为地址范围 
3. CIDR：
    192.168.60.5/24 表示前 24 位是网络 ID
    除去网络 ID，剩余都是主机 ID
4. ip -br address 显示 IP 地址
5. ip addr add 手动分配 IP 地址
6. 自动分配 IP 地址：
    - DHCP
7. dig www.example.com 获取域名的 IP 地址
